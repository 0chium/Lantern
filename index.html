Native controls. Warm light.

Lantern adds a warm flashlight control to Control Center. Tap to toggle, or open the expanded control to adjust brightness with Apple's native intensity slider. Apple's stock flashlight remains available for white light.

Warm/yellow outputAn alternative to the stock white flashlight.
Native intensity controlAdjust brightness in the expanded view.

The expanded ON header combines a white and translucent-white lantern with yellow flame and rays. The intensity slider keeps its native appearance.

Known limitations
  • Switching between Lantern and Apple's flashlight at the same brightness may require a second interaction to update physical output.
  • Apple's expanded flashlight intensity interface can display its active indicator while Lantern is operating.

Install from 0chium's Repo

Open this page in Safari on your jailbroken iPhone and use the source-add buttons above. If your package manager does not open, add the repository URL manually.

Manual source-add instructions
  1. Copy the HTTPS URL above.
  2. Open Sources in Sileo or Zebra and choose its add-source action.
  3. Paste the URL, confirm, then refresh sources.
  4. Find Lantern 0.1.2-1 and install through the package manager.

Initially unsigned. Sileo source-add handoff is confirmed. Live package-manager compatibility and Zebra handoff remain unverified on the device.

Activation, updates & removal

Activate after installation

Turn the flashlight off and close Camera before package installation, updates or removal. Use your package manager for all three operations.

The package has no automatic activation scripts. On the verified environment, restart cameracaptured and reload SpringBoard using these root-shell commands:

/var/jb/usr/bin/killall -TERM cameracaptured
/var/jb/usr/bin/sbreload

A respring alone is not the verified complete procedure. Repeat the activation procedure after updates or removal. Add Lantern using Control Center's editing controls.
